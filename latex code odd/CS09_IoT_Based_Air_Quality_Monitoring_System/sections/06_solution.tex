\subsection{Empirical Findings and Performance Discussion}
The quantitative results confirmed substantial operational advantages:
\begin{itemize}
  \item \textbf{Resource Conservation:} Real-time telemetry and closed-loop edge automation reduce resource consumption by over $40\%$, mitigating operational expenses and environmental impact.
  \item \textbf{Telemetry Reliability:} The integrated protocol stack achieved a packet delivery ratio exceeding $99\%$, maintaining link stability across non-line-of-sight urban canyons and dense foliage.
  \item \textbf{Latency and Responsiveness:} Sub-second edge detection and dispatch latencies allow immediate corrective actuation, safeguarding assets and human lives against acute threshold excursions.
\end{itemize}

\subsection{Security, Integrity, and Scalability}
All payloads are encrypted at the edge using AES-128 in Counter with CBC-MAC (CCM) mode, preventing eavesdropping and packet injection attacks. Unique hardware-fused device certificates prevent rogue nodes from authenticating with the cloud gateway.
